# Выбор агента при установке: план реализации

> Выполнить в текущей сессии в отдельном worktree. Основание: принятые требования
> [issue #6](https://github.com/mesilov/pdlc-llm-wiki4sdlc-skill/issues/6),
> milestone 0.1.0 и поручение пользователя взять задачу в работу.

**Goal:** добавить выбор Claude Code, Codex или OpenCode в существующий установщик.

**Architecture:** сохранить одну копию восьми навыков в `.agents/skills`.
Claude Code получает существующие относительные aliases `.claude/skills`.
Codex и OpenCode используют `.agents/skills` непосредственно. Выбор агента
происходит до построения плана и любых записей; preflight остаётся общим.

**Tech Stack:** Python 3.10+, стандартная библиотека, unittest.

## Решение по интерфейсу

- `--agent claude|codex|opencode` выбирает агента без вопросов.
- Старый `--claude` означает `--agent claude`; сочетание с другим агентом
  отклоняется. Сочетание с `--agent claude` допустимо.
- Без этих флагов при `stdin.isatty()` показать три пункта меню с вводом
  номера либо имени. Ошибочный ввод повторяет вопрос. `q`, EOF и Ctrl-C
  завершают запуск до записи: коды 0, 2 и 130 соответственно.
- Без TTY и без флагов использовать Codex, сохраняя прежнюю установку
  в `.agents/skills` и не читая stdin.
- После preflight вывести выбранного агента, каталог проекта, канонический
  путь skills, aliases при необходимости и путь CLI, затем выполнить план.
- Существующие `--init-wiki`, `--dry-run`, запрет конфликтующих файлов,
  комплектность и запрет установки в checkout набора сохраняются.

Дополнительный установщик дублировал бы preflight. Независимые копии навыков
в трёх каталогах потребовали бы синхронизации. Поэтому расширяем текущий скрипт
и сохраняем канонический каталог. Общий контракт, профиль и CLI не меняются.

## Источники каталога обнаружения

Проверены 2026-10-09:

- [Codex](https://learn.chatgpt.com/docs/build-skills): repository `.agents/skills`.
- [Claude Code](https://code.claude.com/docs/en/skills): project `.claude/skills`,
  symlinked skill folders поддерживаются.
- [OpenCode](https://opencode.ai/docs/skills/): agent-compatible `.agents/skills`.

Документация подтверждает схему discovery; отдельные проверки установленными
CLI должны подтвердить обнаружение восьми навыков в временных проектах.
