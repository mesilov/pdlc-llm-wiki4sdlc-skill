# Проверка переносимости — 2026-10-05

## Исходная версия

На перенесённом, ещё не адаптированном CLI запущены новые сценарии профиля.
Шесть ожидаемых failures показали: обязательный OpenSpec блокирует четыре
команды; независимые raw/knowledge и переименованные supporting файлы не
поддерживаются; свой naming convention решений и выключенный glossary
не поддерживаются.

Независимый агент прочитал исходные восемь skills и общий контракт и применил
их к лаборатории с docs/evidence, docs/wiki, navigation.md, terms.md и без
OpenSpec. Все восемь операций были заблокированы исходными предусловиями.
Он также выявил требование переносить CLI вместе с общим ресурсом.

## Адаптированная версия

Повторная независимая проверка того же сценария использовала только новый
комплект и профиль лаборатории: language=en, domains=topics, decisions=adr,
имя ADR-[0-9]+.md и статусы draft/approved/replaced с пояснениями в schema.

| Операция | Проверенный результат инструкций |
| --- | --- |
| query | Реальные пути из профиля; ответ на английском; без записи или log |
| ingest | Новый snapshot; сохранение старого evidence и contradiction |
| research | Даты/region/plan для pricing; ответ в canonical topic |
| update | Affected + semantic search; только реальные downstream implications |
| audit | Проверка claims и источников; report-only не записывает wiki |
| lint | terms.md вместо GLOSSARY.md; значение отделено от применения |
| merge | Уникальное знание, conflicts и inbound links сохраняются |
| decide | ADR record со статусом draft; отсутствие формализации явно указано |

OpenSpec null не блокирует ни одну процедуру. CI, публикация и реализация
не возникают из выполнения wiki workflow. По этой проверке реальных
противоречий в инструкциях не найдено. Это сценарная проверка принятия
решений по тексту, а не свидетельство выполнения восьми продуктовых задач.

## Семь линз и трассировка сценариев — 2026-10-06

По принятому варианту семь тематических линз заменили восемь представлений

Это сценарная проверка инструкций, а не выполнение исследования инвайтов.

На временных синтетических корпусах с копией CLI проверены случаи:

| Случай | Результат |
| --- | --- |
| Один из двух OpenSpec Scenario без основания | Scenario 1/2; `E_TRACE_SCENARIO_UNLINKED`; trace/lint exit 1 |
