# Первичные материалы

Дефолтные категории задаёт `raw_categories: ["sources", "research"]` в профиле проекта.

| Категория | Назначение |
| --- | --- |
| [sources](sources/README.md) | Исходные документы, интервью, наблюдения, скриншоты, логи и результаты проверок с provenance |
| [research](research/README.md) | Вопрос, методика, сравнение и отчёт исследования со ссылками на исходные материалы |

Дерево группируется по теме и датированной единице:

```text
raw/
  sources/
    <topic>/
      YYYY-MM-DD-<slug>/
        README.md
        <original files>
  research/
    <topic>/
      YYYY-MM-DD-<slug>/
        README.md
        <research artifacts when needed>
```

Корневой README.md каждой новой единицы обязателен: UTF-8 Markdown с YAML frontmatter по форме OKF v0.2.
Минимальные поля: `type`, `title`, `description`, `sources`.
README.md объясняет происхождение, дату получения, версию, контекст, состав файлов и ограничения.
Для исследования добавьте вопрос, методику и выводы с основаниями.
Оригиналы сохраняйте в исходном формате; новый снимок не заменяет старый.
Интерпретация принадлежит слою знаний. Категория и метаданные не подтверждают реализацию или runtime.

Явный список категорий заменяет defaults, включая `[]`.
Назначение своих категорий и формат единиц опишите в схеме проекта.
Прежние папки и материалы сохраняются до явного запроса миграции.
`bin/wiki/raw-lint --json` детерминированно проверяет frontmatter и дерево корневых единиц.
Для команды нужен PyYAML из bin/wiki/requirements.txt; установите его явно в окружении проекта.
Для собственной схемы, заменяющей raw-контракт, используйте `--okf-only` и проверки проекта.
Содержание, происхождение и ограничения проверяет агент по references/raw.md установленного wiki-query.

См. [схему wiki](../knowledge/SCHEMA.md).
