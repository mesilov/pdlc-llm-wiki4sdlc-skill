# Описания изменений для релиза

Для изменений skills, CLI, профиля, установки или шаблонов добавьте changeset:

```bash
npm ci
npm run changeset
```

Выберите `pdlc-llm-wiki4sdlc-skill`, тип `patch`, `minor` или `major` и опишите
изменение для пользователя. Markdown-файл включите в PR вместе с правками.
Несколько changesets объединяются в одну версию всего комплекта.

Для правок только CI или документации changeset необязателен, если они не меняют
использование комплекта. Не редактируйте версию вручную: бот готовит release PR.
Начальная версия `0.0.0` — техническая; первый changeset выпускает `0.1.0`.

Полный процесс: [docs/releases.md](../docs/releases.md).
